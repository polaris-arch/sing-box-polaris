# Polaris-box on OpenWrt

Use the `x86_64` package for generic 64-bit x86, or `aarch64_generic` for generic ARMv8-A. Use `.ipk` on OpenWrt 24.10 (opkg) and `.apk` on OpenWrt 25.12 (apk3). These packages statically link the fixed musl Cronet library and include Naive and gVisor. No separate libcronet, OpenSSL replacement or user compilation is needed. All archived payload/control filesystem entries are root:root (0:0), checked in final package metadata and installed paths. Kernel module dependencies must match your installed OpenWrt kernel; do not force incompatible modules.

The package identity is `polaris-box`. Its executable, UCI configuration and procd service retain the `sing-box` paths. It conflicts with an installed `sing-box` package and does not silently replace that package. Before migrating, stop the old service and make an independent backup of `/etc/config/sing-box` and `/etc/sing-box/config.json`. Remove the old package explicitly, restore your saved configuration if necessary, and install the matching Polaris package using your package manager. Do not use force-overwrite or force-dependency options.

New installations start disabled and contain no listener or shared password. Edit `/etc/sing-box/config.json`, run `sing-box check -c /etc/sing-box/config.json`, and then explicitly set UCI `sing-box.main.enabled=1`, commit the configuration, enable and start `/etc/init.d/sing-box`. Upgrades preserve existing configuration and restart the service only when it was already running before the explicit package operation. A new installation stays disabled. If a package operation is interrupted, preserved install snapshots remain under `/etc/polaris-box/install-snapshot` for administrator recovery. On removal, configuration is retained; a copy also remains under `/etc/polaris-box/retained-config`. Review retained copies yourself before deleting them.

Naive TLS uses normal certificate verification. `ca-bundle` is a package dependency. Custom roots require explicit configuration; do not disable verification as a workaround. TUN requires the matching `kmod-tun` and sufficient permissions. The package does not automatically edit routes, nftables or your network configuration.

The release asset index records the final source, complete module graph, SDK/compiler identity, Cronet static-library hashes, build flags, package contents and validation scope. Automatic GitHub Source code archives supply the fixed product code, including its modified local dependency; the same index supplies fixed public sources for unmodified external inputs and compiler/runtime source with OpenWrt patch bindings. Package signatures and local guest validation do not assert real-device acceptance. Mobile and Polaris App acceptance are separate.

APK archives are currently unsigned. Before installation, verify the exact local archive against the independently frozen published index/SHA256SUMS. Use `apk add --allow-untrusted /tmp/<verified-local-polaris-box-package>.apk` only for that one checked local file. This is explicit acceptance of an unsigned local package, not publisher-signature validation; it does not authorize untrusted remote repositories or a persistent global untrusted setting. The release retains `signatureTrustValidated=false`.
